# 🌶️ About Foodie's Kitchen

**Foodie's Kitchen** is a modern Indian restaurant website designed to present a complete digital dining experience through a warm, traditional, and elegant interface.

The website brings together:

- 🏠 Restaurant information
- 🍛 Food menu
- 🖼️ Food and ambiance gallery
- 📅 Table reservations
- 📍 Contact information
- 🛒 Shopping cart
- 💬 Customer feedback
- 🔐 Login page
- 📝 Sign-up page

The project is built entirely with **HTML5 and CSS3**, without using any frontend framework or backend.

---

# 🎨 Design Concept

The website uses a warm Indian-inspired visual language to create a welcoming and cultural restaurant atmosphere.

### 🎨 Color Inspiration

- 🟤 Walnut / Deep Maroon
- 🟡 Amber / Gold
- 🟢 Pine Green
- 🌹 Rose
- 📜 Traditional Paper Tones

The overall design goal is to make the website feel:

> **Welcoming • Cultural • Elegant • Modern • Easy to Navigate**

# 📄 Website Pages

|---|---|---|
| `index.html` | 🏠 Home | Landing page with Foodie's Kitchen branding, navigation, hero section, and featured content |

# 📱 Responsive Design

Foodie's Kitchen is designed to adapt to different screen sizes.

## 💻 Desktop

**Above 950px**

- Full multi-column layouts
- Desktop navigation
- Spacious content sections
- Large gallery layouts

## 📲 Tablet

**601px – 950px**

- Reduced column layouts
- Flexible content sections
- Tablet-friendly spacing
- Optimized navigation

## 📱 Mobile

**Up to 600px**

- Single-column layouts
- Optimized typography
- Mobile-friendly spacing
- Responsive content

## 📱 Small Mobile

**Up to 400px**

- Further layout adjustments
- Smaller spacing
- Improved readability
- Optimized mobile presentation

# 🚀 How to Run

## 1️⃣ Download or Clone

Download the project folder to your computer.

## 2️⃣ Open the Project

Open the project in your preferred code editor.

Example:

```text
Foodies-Kitchen/
```

## 3️⃣ Open the Website

Open:

```text
index.html
```

in a modern web browser.

## 4️⃣ Recommended Development Setup

For a better development experience, use:

**VS Code Live Server**

No build steps, package installations, or backend server are required.

This is a static **HTML and CSS** website.
